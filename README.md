# Debian 12 VPS 初始化与安全加固脚本

本脚本适用于 **Debian 12** 系统的云服务器（VPS）初始化部署，集成用户管理、安全加固、网络优化与系统性能调优功能，适用于科研服务器、个人开发环境或生产环境基础部署。

---

## 🚀 功能概述

本脚本实现以下自动化配置流程：

---

## 1️⃣ 用户管理

- 交互式输入用户名
- 若用户不存在：自动创建用户并初始化 Home 目录
- 若用户已存在：跳过创建步骤，直接用于后续配置
- 自动创建常用目录：
  - `project`
  - `workspace`
  - `data`
  - `script`
- 自动加入 `sudo` 组，支持管理员权限

---

## 2️⃣ 主机信息配置

- 交互式修改系统 `hostname`
- 即时生效（基于 `hostnamectl`）

---

## 3️⃣ SSH 安全加固（强制 Key 登录）

- 必须提供 SSH 公钥
- 自动为指定用户写入 `authorized_keys`
- 禁用 SSH 密码登录
- 禁止 root 通过 SSH 登录
- 强制仅允许指定用户 SSH 登录（`AllowUsers`）
- 支持自定义 SSH 端口
- 自动重载 SSH 服务

> ⚠️ 设计为“防锁死模式”：若未提供公钥，则不会执行 SSH 加固

---

## 4️⃣ 防火墙配置（UFW）

- 自动放行当前 SSH 端口
- 默认拒绝所有入站连接
- 默认允许所有出站连接
- 自动启用 UFW

---

## 5️⃣ fail2ban 防爆破机制

- 自动安装并启用 `fail2ban`
- 监听 SSH 登录日志
- 5 次失败尝试自动封禁 IP
- 默认封禁时间：6 小时
- 与 UFW 联动执行封禁

---

## 6️⃣ 基础工具安装

自动安装常用运维工具：

- `curl`
- `git`
- `vim`
- `htop`
- `ufw`
- `fail2ban`

---

## 7️⃣ APT 下载优化

自动写入 APT 优化配置：

- 自动重试机制
- HTTP/HTTPS 超时控制
- 并发访问优化
- 保留旧配置策略

---

## 8️⃣ 时区设置

- 自动设置为：`Asia/Hong_Kong`

---

## 9️⃣ Swap 优化

- 设置：
  - `vm.swappiness = 10`
  - `vm.vfs_cache_pressure = 50`
- 可选自动创建 `swapfile`
- 自动写入 `/etc/fstab`

---

## 🔟 网络性能优化（BBR）

- 启用 `fq` 队列调度
- 启用 `tcp_bbr` 拥塞控制算法
- 自动写入 sysctl 配置
- 自动加载模块

---

## 🔒 最终安全策略总结

执行完成后，系统具备：

- ❌ root 无法 SSH 登录
- 🔑 仅允许指定用户使用 SSH Key 登录
- 🚫 禁止密码登录
- 🛡 SSH 爆破自动封禁
- 🔥 UFW 默认拒绝入站访问
- ⚡ BBR 网络优化启用

---

## ⚠️ 使用建议

- 执行前请准备好 SSH 公钥
- 执行后请 **在新终端窗口测试 SSH 登录**
- 确认新用户可正常登录后再关闭当前会话
